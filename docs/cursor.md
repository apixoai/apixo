# Cursor

_Use Apixo models inside Cursor._

1. Open **Settings → Models**.
2. Under **OpenAI API Key**, paste your `sk-apixo-YOUR_KEY` key.
3. Enable **Override OpenAI Base URL** and enter `https://api.apixoai.online/v1`.
4. Add custom models, e.g. `gpt-6-astra`, `claude-fable-5`.
5. Click **Verify**.

Cursor sends requests in OpenAI format; every model we offer works through it.
