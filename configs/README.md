# Ready-to-use config files

Replace `sk-apixo-YOUR_KEY` with your real key from https://apixoai.online/dashboard — or download the same files **with your key already filled in** from [Dashboard → Setup](https://apixoai.online/dashboard/setup) or the Telegram bot (`/setup`).

| Tool | File | Save it as |
|---|---|---|
| OpenCode | [opencode/opencode.json](opencode/opencode.json) | `~/.config/opencode/opencode.json` (Windows: `%USERPROFILE%\.config\opencode\opencode.json`) |
| Claude Code | [claude-code/settings.json](claude-code/settings.json) | `~/.claude/settings.json` |
| Continue | [continue/config.yaml](continue/config.yaml) | `~/.continue/config.yaml` |
| Codex CLI | [codex/config.toml](codex/config.toml) | `~/.codex/config.toml` |

Cline, Roo Code, Cursor and others are set in the app's settings screen — see [docs](../docs/README.md).

> Never commit your real key to a public repo. Anyone with it can spend your balance.
