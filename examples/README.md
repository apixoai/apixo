# Examples

Set your key first: `export APIXO_API_KEY=sk-apixo-YOUR_KEY` (Windows PowerShell: `$env:APIXO_API_KEY="sk-apixo-YOUR_KEY"`).

- [curl.sh](curl.sh) — OpenAI and Anthropic format, list models
- [openai_python.py](openai_python.py) — streaming with the OpenAI SDK
- [anthropic_python.py](anthropic_python.py) — Anthropic SDK
- [openai_node.mjs](openai_node.mjs) — Node.js / TypeScript

Every model works with both formats.
